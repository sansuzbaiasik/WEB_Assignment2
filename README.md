## Summary
In this assignment, I implemented advanced CSS layout techniques using Flexbox and CSS Grid without relying on external frameworks. The main layout structure utilizes CSS Grid to define clear areas for the header, sidebar, main content, and footer. Inside the main content, I combined Grid and Flexbox: CSS Grid is used to separate the projects area from the info sidebar, while Flexbox is used to align the navigation links, equalize card heights, and arrange content inside the project cards. I also built a responsive image gallery using a 3-column grid setup with interactive hover states displaying overlay captions. This project successfully demonstrates effective alignment, spacing, and structural design using modern CSS capabilities.
